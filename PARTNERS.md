# ASIYA Islamic Partners — управление размещениями

Рекламные карточки управляются файлом `partners.json` в корне репозитория. Пустой массив `partners` означает, что рекламы нет. После сохранения изменений GitHub Pages обновит опубликованный файл.

## Пример записи (не включена в приложение)

```json
{
  "version": 1,
  "partners": [
    {
      "id": "example-education-2027",
      "placement": "learning",
      "title": "Название проверенного партнёра",
      "description": "Краткое, достоверное описание предложения.",
      "url": "https://example.org/",
      "enabled": false,
      "startAt": "2027-01-01T00:00:00+01:00",
      "endAt": "2027-02-01T00:00:00+01:00"
    }
  ]
}
```

Поля: `id` — уникальный идентификатор (строчные латинские буквы, цифры, дефис, до 48 символов); `placement` — `home` или `learning`; `title` и `description` — тексты карточки; `url` — HTTPS-ссылка; `enabled` — `true` для показа, `false` для отключения. `startAt` и `endAt` необязательны; при использовании указывайте полную дату со смещением часового пояса, как в примере.

В каждом разделе показывается максимум одна карточка; порядок определяется порядком записей в массиве. До публикации проверьте соответствие партнёра тематике приложения, достоверность текста, права на материалы и безопасность сайта. Реклама всегда помечается, не вставляется в аяты и не сопровождается автоматическим звуком. Приложение не отправляет аналитику рекламодателям.

Для предпросмотра дизайна без реальной рекламы: `?partnerPreview=1&placement=home` или `?partnerPreview=1&placement=learning`. Демонстрационная карточка не ведёт на внешний сайт.
