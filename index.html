Пословный разбор Аль-Фатихи · учебный режим (раскрыть)

Экспериментальный учебный разбор 1:1–1:7. Русские значения слов пока не прошли независимую проверку специалистом. Для Аль-Фатихи добавлена предварительная латинская пословная транслитерация; она ещё не прошла независимую проверку специалистом. Не используйте её вместо арабского текста или проверенного аудио. Цветовая разметка таджвида пока не реализована.

Источники текста и ограничения перевода

Предпочитаемый арабский источник (если файл успешно проверен): Tanzil Quran Text (Uthmani, Version 1.1), Copyright © 2007–2021 Tanzil Project, Creative Commons Attribution 3.0. Оригинальный текст распространяется без изменений. Tanzil Project · Условия использования и полное уведомление · Обновления. ASIYA автоматически проверяет встроенный файл по SHA-256; при отсутствии проверенного файла использует AlQuran Cloud и показывает источник. Локальная читалка Tanzil доступна для независимой проверки. По умолчанию используется русский перевод смыслов Эльмира Кулиева. Другие переводы доступны для онлайн-чтения при наличии данных у API. Офлайн-библиотека пока сохраняет русский перевод. Латинская транслитерация — en.transliteration; это не русская транскрипция и не учебник таджвида.

Перевод передаёт смысл, а не заменяет арабский оригинал. Пословный учебный разбор Аль-Фатихи находится отдельно и требует дополнительной проверки. Цветовой таджвид пока не включён.

Источник данных: AlQuran.Cloud API. При отсутствии интернета отдельные переводы могут быть недоступны.
